# 05 — Governança, Ética e Proteção de Dados

## 1. Objetivo

Definir princípios para o uso responsável dos dados na plataforma Saúde Antes da Emergência.

## 2. Princípios

- Transparência sobre fontes e transformações.
- Rastreabilidade dos dados.
- Integridade e qualidade das informações.
- Minimização de dados.
- Segurança e controle de acesso.
- Equidade na interpretação dos resultados.
- Responsabilidade na comunicação dos indicadores.

## 3. Proteção de dados e LGPD

O projeto priorizará a utilização de dados públicos agregados, evitando a coleta de informações pessoais identificáveis.

A Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018) deverá orientar o tratamento de qualquer dado pessoal eventualmente utilizado.

Fonte: https://www.planalto.gov.br/ccivil_03/_ato2015-2018/2018/lei/l13709.htm

## 4. Riscos e medidas de mitigação

| Risco | Medida de mitigação |
|---|---|
| Dados incompletos | Indicadores de completude |
| Atraso nas notificações | Exibir período e data de atualização |
| Diferenças entre municípios | Documentar critérios de comparação |
| Viés territorial | Avaliar cobertura e limitações |
| Interpretação incorreta | Explicar os fatores do índice |
| Acesso indevido | Controle de acesso e permissões |

## 5. Segurança

A proposta considera três dimensões:

- Confidencialidade: acesso restrito conforme a necessidade.
- Integridade: preservação e validação dos dados.
- Disponibilidade: organização e continuidade do acesso à plataforma.

## 6. Perfis de acesso propostos

- Administrador: configurações e gestão da plataforma.
- Analista: tratamento e validação dos dados.
- Gestor público: consulta aos indicadores e relatórios.
- Agente de saúde: consulta às informações necessárias ao planejamento de ações.

Os perfis serão implementados somente se forem necessários ao escopo da POC.

## 7. Limites éticos

A plataforma não deverá utilizar os indicadores para estigmatizar comunidades ou responsabilizar moradores por condições territoriais.

Os resultados deverão ser apresentados como apoio à decisão, e não como substitutos da avaliação técnica dos profissionais de saúde.

## 8. Revisão

As políticas e os controles deverão ser revisados conforme a evolução do projeto e a definição dos dados efetivamente utilizados.
