# Evidências — Google BigQuery

## 1. Objetivo

Esta pasta reúne evidências visuais da implementação do ambiente analítico do projeto Saúde Antes da Emergência no Google BigQuery.

## 2. Evidências previstas

As capturas de tela deverão demonstrar:

1. Projeto Google Cloud utilizado.
2. Dataset `saude_antes_emergencia`.
3. Estrutura de tabelas disponíveis.
4. Consultas SQL de integração.
5. Painel municipal integrado.
6. Auditorias de cobertura e qualidade.
7. Estruturas de indicadores normalizados.

## 3. Critérios para publicação

As capturas deverão:

- Mostrar apenas informações autorizadas para divulgação.
- Não expor credenciais, tokens ou dados pessoais.
- Identificar claramente o contexto da evidência.
- Preservar legibilidade dos nomes de tabelas e resultados.
- Ser acompanhadas de descrição e data de captura.
