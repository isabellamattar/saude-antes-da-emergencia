# Evidências — Arquitetura do Projeto

## 1. Objetivo

Esta pasta reúne representações visuais da arquitetura tecnológica do projeto Saúde Antes da Emergência.

## 2. Evidências previstas

- Diagrama da arquitetura lógica.
- Fluxo de coleta e transformação.
- Integração entre fontes públicas e BigQuery.
- Componentes planejados para visualização e aplicação web.

## 3. Critérios de documentação

Cada evidência deverá apresentar:

- Título.
- Descrição.
- Data de elaboração ou captura.
- Identificação dos componentes representados.
- Distinção entre serviços implementados e planejados.

Diagramas conceituais não devem ser apresentados como comprovação de serviços implantados.
